## Что предстоит реализовать (по спеке, §0–§12)
Канонная модель (§2) · KPI-движок: Wilson-интервалы, CPA для search/network, сглаженные CTR/CR (§3) · контракт адаптера (§4) + `MockYandexDirect` с двумя моделями аукциона и «оракулом» (§5) · ядро оптимизации: гейт значимости, контроллер ставок→CPA, Thompson-bandit бюджета единым пулом, prune/scale (§6) · guardrails-инварианты (§7) · цикл-оркестратор по порядку §8 · память + лог решений (§9) · объяснимость каждого решения (§10) · конфиг в одном месте (§11) · демо-прогон + артефакты приёмки (§12).

## Технические рамки
- Python 3.x, numpy/pandas. Хранение — in-memory или SQLite (обоснуй выбор в плане).
- Детерминизм: глобальный `SEED`, RNG тика = f(SEED, tick). Прогоны воспроизводимы.
- Никаких внешних API/сетей.
- Все параметры — в одном модуле конфига (§11), значения по умолчанию из спеки.
- Бейзлайны для приёмки: (a) равный бюджет + фикс. ставка; (b) оракул на истинных параметрах мока.
